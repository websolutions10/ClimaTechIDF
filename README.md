# Climatec - Site Web Professionnel

Site web moderne et responsive pour Climatec, spécialiste en climatisation en Île-de-France.

## Organisation des Photos

Pour ajouter vos photos de chantiers, utilisez la structure de dossiers suivante :

### Structure des dossiers images :
```
public/
├── images/
    ├── projects/          # Photos principales des projets
    │   ├── project-1.jpg
    │   ├── project-2.jpg
    │   ├── project-3.jpg
    │   └── ...
    ├── gallery/           # Photos pour la galerie complète
    │   ├── residential/   # Projets résidentiels
    │   ├── commercial/    # Projets commerciaux
    │   └── heatpump/      # Pompes à chaleur
    └── services/          # Photos pour les pages services
        ├── installation.jpg
        ├── maintenance.jpg
        └── depannage.jpg
```

### Format et nommage recommandés :

**Format :** JPG ou PNG, optimisé pour le web (< 500KB par image)
**Résolution :** 1200x800px minimum pour une qualité optimale
**Nommage :** Utilisez des noms descriptifs :
- `project-villa-draveil-2024.jpg`
- `installation-split-mural-creteil.jpg`
- `maintenance-bureau-evry.jpg`
- `pompe-chaleur-corbeil.jpg`

### Catégories pour la galerie :
- **residential/** : Maisons, appartements, villas
- **commercial/** : Bureaux, magasins, restaurants
- **heatpump/** : Pompes à chaleur air/air, air/eau

### Conseils pour les photos :
1. **Avant/Après** : Montrez la transformation
2. **Détails techniques** : Unités extérieures, passages de gaines
3. **Finitions** : Mettez en valeur la propreté du travail
4. **Environnement** : Montrez l'intégration dans l'espace
5. **Équipe** : Photos de l'équipe en action (avec autorisation)

Une fois vos photos ajoutées dans les dossiers, le site les affichera automatiquement avec un système de fallback vers des images de démonstration.
